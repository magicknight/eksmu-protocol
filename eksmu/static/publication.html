离线核对方法
使用配套程序运行 python -m eksmu verify-publication 下载文件.json --expect-sha256 此页固定版本摘要。如需另存私有本地承诺，先运行 python -m eksmu create-time-evidence 下载文件.json 私有证据包.json，再用 verify-time-evidence 离线核验。证据包包含正文、材料与随机数，须自行私下保存。这些命令不访问网络、不执行附件，也不证明外部时间。
