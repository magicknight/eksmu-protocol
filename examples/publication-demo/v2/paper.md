## 摘要

我们为 4 至 10000 的每个偶数记录一对素数，其和等于该偶数。筛法生成 4999 行见证，另一份不导入筛法程序的试除检查器核对完整覆盖、端点、素性与加法。全部 4999 行通过有限见证检查。本文的目的在于提供一份可阅读、可复算、可讨论并能固定材料版本的完整发表演示；不宣称证明一般哥德巴赫猜想，不包含 Lean 证明或官方验收。

## 1. 问题与范围

设 $E_U=\{n\in\mathbb{Z}:4\leq n\leq U,\ n\text{ 为偶数}\}$，本版取 $U=10000$。目标是为每个 $n\in E_U$ 给出素数 $p,q$，满足 $2\leq p\leq q$ 且 $p+q=n$。目标数的个数为 $U/2-1=4999$。两端均包含，特别是允许 $p=q=2$。

选题来自项目 M01 探索卡及参考资料 [1] 中的 JSP-000008。本文限定了有限上界；一般问题涉及所有大于 2 的偶数。有限清单无法排除更大数上的失败，因而不能把本次成功外推成一般命题的证明。

## 2. 生成方法

`generate.py` 先把 0、1 标为非素数，从 2 起筛去每个候选素数的倍数。对于筛选位置 $p$，从 $p^2$ 开始：小于 $p^2$ 的合数倍数已有较小素因子。只需筛至平方根的整数部分，因为任何合数 $m=ab$ 都存在一个不超过 $\sqrt{m}$ 的因子。

随后按递增顺序遍历每个目标偶数，对 $2\leq p\leq n/2$ 搜索并令 $q=n-p$，记录第一对两项均被标为素数的结果。没有找到时程序报错，不能把遗漏当作成功。第一对只是生成时的确定性选择；本文不主张最优性，也不统计全部表示数。

输出为 ASCII CSV，表头严格为 `n,p,q`，每个偶数一行，按 n 递增，不附时间戳或机器名称。文件以 LF 换行，便于按字节复算。

## 3. 与生成器分开的复查

`check.py` 不导入生成器，也不使用其筛表。检查器由文件外给定上界，要求恰有 4999 行，且第 k 行的 n 等于对应的目标偶数；这样可发现漏行、重复、错序和错误范围。对每行再核对 $2\leq p\leq q\leq n$、$p+q=n$，并分别对 p、q 做整数试除。

试除依次检查 $d=2,3,\ldots$，直到 $d^2>x$。若 $x\geq2$ 且没有整除因子，则由上述因子界可判定 x 为素数。这里避免以浮点平方根作为终止条件。两个程序采用不同判定路径，但同由本次 AI 工作流程编写；不能称为独立人员的复核或形式化认证。

## 5. 复算与讨论入口

将本版附件放在同一目录后，在可审阅的本地环境使用 Python 3 执行：

```sh
python generate.py --upper 10000 > regenerated.csv
python check.py regenerated.csv --upper 10000
python check.py witnesses.csv --upper 10000
```

两份数据的报告应具有相同摘要、4999 个偶数和 `finite_witness_check: PASS`。平台仅保存附件，不会因上传这些命令或代码而执行它们。
