\section{演示：有限哥德巴赫见证的生成与逐行复查}\label{ux6f14ux793aux6709ux9650ux54e5ux5fb7ux5df4ux8d6bux89c1ux8bc1ux7684ux751fux6210ux4e0eux9010ux884cux590dux67e5}

版本 v1 · 包含端点的区间 {[}4, 1000{]} · 私有软件验收材料

署名：演示作者（自动化测试身份）。本文、程序及修订情境由 AI
助手为本项目编写；计算结果来自所附程序的实际运行。未声称有真实独立审稿人参与，也不代表用户提交数学研究或申请奖金。未声明对外许可。

\subsection{摘要}\label{ux6458ux8981}

我们为 4 至 1000 的每个偶数记录一对素数，其和等于该偶数。筛法生成 499
行见证，另一份不导入筛法程序的试除检查器核对完整覆盖、端点、素性与加法。全部
499
行通过有限见证检查。本文的目的在于提供一份可阅读、可复算、可讨论并能固定材料版本的完整发表演示；不宣称证明一般哥德巴赫猜想，不包含
Lean 证明或官方验收。

\subsection{1. 问题与范围}\label{ux95eeux9898ux4e0eux8303ux56f4}

设 \(E_U=\{n\in\mathbb{Z}:4\leq n\leq U,\ n\text{ 为偶数}\}\)，本版取
\(U=1000\)。目标是为每个 \(n\in E_U\) 给出素数 \(p,q\)，满足
\(2\leq p\leq q\) 且 \(p+q=n\)。目标数的个数为
\(U/2-1=499\)。两端均包含，特别是允许 \(p=q=2\)。

选题来自项目 M01 探索卡及参考资料 {[}1{]} 中的
JSP-000008。本文限定了有限上界；一般问题涉及所有大于 2
的偶数。有限清单无法排除更大数上的失败，因而不能把本次成功外推成一般命题的证明。

\subsection{2. 生成方法}\label{ux751fux6210ux65b9ux6cd5}

\texttt{generate.py} 先把 0、1 标为非素数，从 2
起筛去每个候选素数的倍数。对于筛选位置 \(p\)，从 \(p^2\) 开始：小于
\(p^2\) 的合数倍数已有较小素因子。只需筛至平方根的整数部分，因为任何合数
\(m=ab\) 都存在一个不超过 \(\sqrt{m}\) 的因子。

随后按递增顺序遍历每个目标偶数，对 \(2\leq p\leq n/2\) 搜索并令
\(q=n-p\)，记录第一对两项均被标为素数的结果。没有找到时程序报错，不能把遗漏当作成功。第一对只是生成时的确定性选择；本文不主张最优性，也不统计全部表示数。

输出为 ASCII CSV，表头严格为 \texttt{n,p,q}，每个偶数一行，按 n
递增，不附时间戳或机器名称。文件以 LF 换行，便于按字节复算。

\subsection{3.
与生成器分开的复查}\label{ux4e0eux751fux6210ux5668ux5206ux5f00ux7684ux590dux67e5}

\texttt{check.py}
不导入生成器，也不使用其筛表。检查器由文件外给定上界，要求恰有 499
行，且第 k 行的 n
等于对应的目标偶数；这样可发现漏行、重复、错序和错误范围。对每行再核对
\(2\leq p\leq q\leq n\)、\(p+q=n\)，并分别对 p、q 做整数试除。

试除依次检查 \(d=2,3,\ldots\)，直到 \(d^2>x\)。若 \(x\geq2\)
且没有整除因子，则由上述因子界可判定 x
为素数。这里避免以浮点平方根作为终止条件。两个程序采用不同判定路径，但同由本次
AI 工作流程编写；不能称为独立人员的复核或形式化认证。

\subsection{5.
复算与讨论入口}\label{ux590dux7b97ux4e0eux8ba8ux8bbaux5165ux53e3}

将本版附件放在同一目录后，在可审阅的本地环境使用 Python 3 执行：

\begin{verbatim}
python generate.py --upper 1000 > regenerated.csv
python check.py regenerated.csv --upper 1000
python check.py witnesses.csv --upper 1000
\end{verbatim}

两份数据的报告应具有相同摘要、499 个偶数和
\texttt{finite\_witness\_check:\ PASS}。平台仅保存附件，不会因上传这些命令或代码而执行它们。

可以继续检查：若删去最后一行、把 10 的见证改为 4 与 6、或将声明范围改为
1002，检查器是否拒绝；更大范围是否仍有见证。下一版可扩大到 M01 卡建议的
10000，同时保留本版数据与讨论，避免将修订后的范围回填进旧记录。
