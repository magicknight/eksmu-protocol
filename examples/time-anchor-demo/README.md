# 无私人材料的外部锚定预检输入

`commitment.hex`是[RFC0016](../../docs/rfcs/0016-local-time-evidence.md)固定向量的64位十六进制结果，由全零快照摘要与固定随机数计算。2026-10-29 更名后域标识为 `eksmu.local-time-evidence.v1`，向量随之变为 `9f33977e…3cbc`；RFC0016 原文记录的是更名前 `oic.` 域标识下的向量。它不是用户作品、不是实际时间存证，也不包含令牌或私有附件。

此文件仅供以后在隔离环境中检查候选适配器的字节处理。**目前没有运行`ots stamp`、连接calendar或广播公共链交易。** 若后续工具需要32字节二进制输入，先将十六进制解码，再记录输入文件摘要与输出证明；不得把文本文件的SHA-256当成这32字节承诺。
