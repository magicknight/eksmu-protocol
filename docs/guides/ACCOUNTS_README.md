# 账户、设备会话与恢复（M2）

账户有稳定作者标识。新注册以私人邮箱＋密码登录；公开显示名称可填真实姓名或笔名，单位由作者自愿填写、修改或清除，并标为作者自述。私人邮箱不会公开。每台设备持有独立会话，可以分别退出；不要求机构归属、实名、钱包或付款。当前私有实例尚未配置 SMTP，邮件验证与找回暂不可用，已登录者可用当前密码改密。完整边界见[RFC0027](../rfcs/0027-email-accounts-public-profiles.md)。

## 旧版恢复文件账户为什么要先保存文件

这套注册方式是M2私有原型的工程选择，不是用户逐项批准的永久产品规则，也不是学术准入条件。浏览作品无需注册；发表、评论和修订需要稳定的作者标识，使后续版本与操作能归属同一人。显示名称不要求唯一，不能单凭名称证明身份。

M2当时没有邮箱找回或其他外部身份服务。浏览器生成随机恢复凭证，服务端只保存摘要；旧版账户换设备或会话到期时，凭证是重新取得原作者身份的依据。因此旧版页面让用户在正式创建前下载文件并确认保存，减少“身份已创建，但唯一可用的恢复材料尚未到手”的风险。注册成功后，各设备使用可分别退出或撤销的短期会话，不在浏览器长期保存恢复凭证。预生成操作编号也使网络响应丢失时可以安全重试同一注册请求。

代价是首次参与需要多次点击并私下保管文件；旧版账户尚未绑定邮箱密码且全部有效恢复材料遗失时，当前系统无法保证找回原身份。页面的“已保存”复选框仅是用户确认，程序无法证明文件真正保存。新注册已改用邮箱和密码；发表仍不以学历、工具、钱包或付款为门槛。

## 页面使用

- **新账户**：填写公开显示名称、私人邮箱和密码，直接注册并登录。邮箱默认不公开；当前没有发信服务，忘记密码暂时不能邮件找回，注册页在提交前提示。
- **公开资料**：登录后可更新显示名称及自愿公开的单位/身份说明，也可清除单位。单位标为作者自述；过去固定的作品版本和快照不因此重写。
- **旧版恢复文件账户**：在折叠的旧版入口输入凭证登录，再用该有效凭证为同一作者标识绑定邮箱密码；历史作品继续属于原账户。邮箱验证成功后旧恢复文件失效、其他设备退出，当前设备保持登录。旧版新建账户入口作为兼容功能暂存，不再是首页主注册流程。旧版文件中的 `credential` 不能作为文章、评论或附件上传。
- **已有旧身份**：浏览器检测到原身份密钥时，会先提示备份，再升级为设备会话。原作者标识、作品、版本与清单保留；升级成功后旧密钥仅用于登录，不再直接用于业务操作。也可以在登录框输入原密钥，或读取旧版身份文件。
- **换设备**：邮箱账户填写邮箱和密码；旧版账户仍可输入恢复凭证或读取旧文件。显示名称本身不是登录凭证，不要求它在全站唯一。
- **退出与撤销**：“退出当前设备”在服务器撤销当前会话；“退出其他设备”保留当前会话。展开会话列表可单独撤销某一设备。已撤销的页面再提交会得到明确错误，刷新后可以重新登录。
- **更换恢复凭证**：输入当前恢复凭证，下载并保存新凭证后确认。作者标识不变，旧恢复凭证和所有旧会话立即失效，当前页面取得一个新会话。仅持有设备会话不能更换恢复凭证。

每个会话的绝对有效期为7天；每个账户最多20个有效会话。到期后用邮箱密码或旧恢复凭证重新登录。当前没有闲置超时、可实际发送的邮箱找回、管理员冒充登录或无凭证找回；已登录邮箱账户可用当前密码更改密码，并撤销其他设备。

网络失败时不要把“没有收到成功响应”等同于“服务器没有提交”。旧版文件注册、登录、凭证更换保留当前标签页的待确认请求，可以重试同一操作；邮箱注册若结果未确认，应先用同一邮箱密码尝试登录核对，避免再次注册。已撤销或过期会话不能通过重试重新生效。退出响应丢失时可再次退出以确认。

临时候选凭证仅保存在该标签页的sessionStorage，成功后移除。正式会话使用HttpOnly、SameSite=Strict Cookie；恢复凭证不长期保存在localStorage。旧版localStorage密钥在迁移确认后移除。本机草稿仍按作者标识保存，退出不删除它们；共享电脑上的草稿保护与账户会话是不同事项。

当前入口只有 `127.0.0.1` HTTP 与 SSH 转发，Cookie没有Secure属性，名称按服务端口区分；同一主机上的其他本地服务不是隔离边界。公网认证需要另行完成HTTPS、入口隔离和运行安全设计，不能把这个开发服务直接暴露到公网。

## 状态与权限

主库原有五张私有账户表：`auth_meta`、`auth_accounts`、`auth_sessions`、`auth_history`、`auth_operations`，新增 `auth_passwords`、`auth_email_challenges`、`auth_profiles`。保存恢复凭证/会话摘要、密码慢速哈希、一次性邮件代码摘要、期限、撤销状态及公开资料，不保存原始秘密。作品记录和内容摘要不重写，普通作品导出不包含这些账户表。邮箱账户的公开作者指纹不对应有效恢复凭证。

旧 `/api/actors` 和未迁移身份的Bearer路径仍用于兼容既有本地脚本；迁移后的原密钥不能通过该路径继续操作。身份轮换只对当前实例有效，旧软件或独立副本不会自动取得撤销信息。普通作品包不是账户迁移包；新身份跨实例恢复需使用完整实例状态或后续专门的身份迁移协议。

HTTP修改请求在跨进程写入锁内完成鉴权和写入；主库记录在取得SQLite写事务后另行复核。撤销先完成的请求不能继续改作品、附件、协作或个人记录。持有本机文件权限的管理员仍属于受信运行者，维护锁不是恶意代码隔离机制。

旧版凭证注册/登录/轮换操作上限为当前实例累计50,000条，达到上限时拒绝新增旧版认证操作并提示维护；已有会话和普通发表不因这个记录上限被判定失效。该限制用于私有原型，不是长期配额方案。2026-09-27 的源码增加了邮箱认证请求按来源和输入标识的进程内限速；当前 VM 已安装的旧运行版本尚未更新。限额随进程重启清零，SSH 转发或反向代理可能让多个使用者共享同一来源地址。公开入口还需要代理层限速与实际入口验收。

密码找回的未知邮箱、已知邮箱冷却期和已知邮箱发信失败现在返回相同的接收确认；已有邮箱重复注册仍返回冲突，真实发信的时延也可能透露账户存在。公开注册前须改为验证邮箱后建立账户的流程，并验收统一响应和时间行为。当前没有 SMTP，真实验证和找回仍不可用。

接口与设计依据见[RFC0013](../rfcs/0013-accounts-sessions-recovery.md)。业务API可使用设备会话Bearer；浏览器用Cookie。同一请求不能同时使用两种业务凭证，秘密不放在URL中。

## 从备份恢复后的凭证核对

[M1完整备份](BACKUP_README.md)包含账户表。恢复先检查原始文件摘要，再**有意撤销全部会话并阻断登录与新注册**，允许读取作品。恢复后的主库文件摘要因此会变化；作品记录与其他组件内容不变。不能以“数据库字节恢复成功”为理由启用旧会话。

恢复命令会显示 `account_review_required=true`。停止恢复实例和作为权威来源的当前实例后，指定最新数据库进行核对：

```bash
python -m eksmu --db /新恢复目录/community.sqlite reconcile-accounts \
  --from-db /当前权威实例/community.sqlite --offline
```

此命令不自动停服或切换端口，两个实例有运行维护锁时会被拒绝。它要求同一实例标识、逐个作者记录一致，并拒绝已知的凭证代数倒退或冲突；更新恢复凭证及历史，所有会话仍保持撤销。之后用户用**当前有效恢复凭证**重新登录，取得新会话。命令不把权威来源中较新的文章复制到旧快照，也不修改权威来源数据库。

维护者必须选择实际最新的权威来源：工具无法探测没有提供的后续变更，也不能证明任意指定副本就是最新。缺少这个来源时，保留登录阻断，不自动信任旧凭证。恢复凭证全部丢失或权威实例完全丢失后的人工重建流程尚未实现。

M1旧快照仍须先用对应旧源码恢复，再升级为M2。旧恢复目录的 `restore-record.json` 会触发同样的登录阻断；旧格式没有账户实例标识，核对时必须逐个匹配不可变作者记录，再绑定权威来源的实例标识。保留这个恢复记录，不通过移除标志绕过核对。

升级前保留匹配的源码和数据快照。**不能只把程序退回M1而继续使用已产生M2账户活动的数据库**，因为旧程序不理解撤销状态；回退必须同时处理数据一致性，不能丢弃升级后的投稿或账户变更。

## 验证

`tests/test_accounts.py` 覆盖迁移、并发、幂等、跨身份权限、过期、撤销、响应丢失、私密数据边界及旧快照核对；纳入 `python scripts/check_integrated.py`。`scripts/demo_backup.py` 在独立应用进程中覆盖两身份、四个数据库、恢复核对与重新登录。

`scripts/browser_accounts.py` 使用真实Chromium、两个测试身份和三个独立浏览器环境，验证下载恢复文件、迁移、登录、撤销、轮换、原作者修订及服务重启。它明确注入两次“服务器提交后丢弃响应”的网络故障，验证轮换与退出重试。报告见浏览器验收。这些是合成测试数据，不是实际用户增长，也不代表已在用户电脑上验证SSH隧道。
