## 已可运行的两个部分

`eksmu/`是从本会话实际取得的v0.2源码包恢复的中文单节点应用，保留原7个应用文件及43项测试，支持化名发表、版本、评论、冲突报告和可信备份迁移。它不是三份v0.3候选的合并版，不包含它们的密钥轮换或持久验证请求。

`verification_lab/` v0.1.0使用独立数据库和权限，读入明确版本摘要，测试准备、单独授权、指定验证器领取、回执、重试和取消。全部固定结果为模拟，不运行AI、Lean或用户程序。

远端另有`eksmu_receipts/`独立签名回执和有限有理数检查器，见docs/guides/RECEIPTS_README.md。它与实验室尚未互通，本轮91项测试不包含其独立测试。

## 运行

本轮实际测试Python3.13.5；基线和实验室只用标准库，不在启动时联网或安装依赖。

```bash
python -m eksmu serve
python -m verification_lab --output fixture-audit.json
python scripts/check_baseline_and_lab.py
```

同一台电脑浏览器打开`http://127.0.0.1:8765`，不能直接作为互联网服务。作品导出不含身份密钥，需要另行私下备份。v0.2尚无密钥轮换或全部密钥丢失后的恢复。

实验室演示只使用合成内容；输出文件新建、不覆盖已有文件。测试入口只运行基线与实验室，91项且无跳过，不是全部并行组件的总测试。

## 权限与信任

准备任务不授权执行。控制任务的凭证不能充当验证器凭证；验证器不能修改社区正文。两个验证器的不同模拟结果可并存，失败或取消不影响继续发表。

重复领取／相同回执幂等，不同结果不覆盖旧回执；再次检查需新授权。取消阻止新领取，已有结果保留，已领取后的完成标为取消后收到。

HMAC只认证本地共享密钥的一方，不是公开数字签名，更不证明数学正确。本机数据库拥有者和密钥持有者仍可信。参考Python官方文档：https://docs.python.org/3/library/hmac.html 。

时间和内存预算仅是校验的声明，不是沙箱；回执输出字节上限有实际检查。作用域也可能含敏感信息，所以审计包仍保持私有。实验室拒绝打开有社区records或不相关表的数据库；只支持明确v1输入，拒绝不明v2，不自动导入外部审计状态。
