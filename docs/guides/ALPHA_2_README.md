## 研究表达与版本

普通文字或Markdown均可发表；支持预览、公式、代码块、表格和草稿恢复。正文HTML/MathML在服务端按固定规则生成并重建允许的标签，不加载远程图片或CDN。未提交修订不因刷新提醒而被重置；提交使用打开编辑时的父版本识别并发冲突。

附件记录原始字节摘要、版本与上传时间。PNG/JPEG/WebP显示重新编码的图片预览，PDF/代码/小型数据以原件下载。附件可在正文发表后追加，因此清单与正文版本分别记录，不把后加材料冒充首次发表时已经存在。原件保留，旧版本可查。

当前本机资源限额：每文件4MiB、每版16件、材料库64MiB。限额作用于资源，不决定发表或讨论资格。

## 开放协作

任何参与者可在他人的探索版本下创建自己的复现、反例、解释、形式化或资料任务，不需作者或专家批准。多人同时加入并记录各自进展；发起者可结束或重开自己的任务，但不能改写他人的历史贡献。

协作事件在探索页显示，也进入“我的动态”；收件规则见[RFC0018](../rfcs/0018-collaboration-notifications.md)。协作任务冲突和响应丢失的反馈见[RFC0019](../rfcs/0019-collaboration-submit-feedback.md)：界面刷新任务、保留当前页面的进展草稿，结果未确认时要求先检查记录再主动重试。它不会自动重复提交，也不承诺跨设备保存进展草稿。

## 保存与恢复

材料包可导出，在恢复相应作品及身份后核对摘要和归属并导入；重复导入不重复写入，错误整包回滚。协作记录可导出，尚无导入外部协作快照为活动任务的接口。M1全实例备份已经覆盖研究数据库，并在独立目录完成恢复验收；操作见[备份说明](BACKUP_README.md)。
