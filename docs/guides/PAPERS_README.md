# 论文资料、引用与固定快照

简单问题仍可直接发表。需要论文资料时，展开发表表单中的“论文资料：摘要、署名与参考文献”，勾选“为本版保存论文资料”，填写摘要、作者与贡献、参考文献、许可声明及既往来源。各项允许留空；新增作者行的署名不能空白，不需要绑定本站账户。

参考文献每行一条。许可由作者自行填写，空白显示“未声明许可”。既往发表日期需同时填写来源，界面明确标为作者自述；它不会覆盖本站保存本版的时间。表单草稿随当前身份保存在本设备，可用“恢复本机草稿”读取。

发表后，资料显示在所选版本正文上方。修改请展开“提交新版本”，编辑正文或论文资料，再保存；旧版本及其评论保留。取消新版本的资料勾选只移除新版本资料，不删除旧版。比较版本时，摘要、作者、许可等变化也会列出。署名中的其他作者可以讨论，编辑权仍属于原发表账户。

“导出全部作品记录”会把正文及各版资料一同保存。含论文资料时导出为 `eksmu.publication-bundle.v1`，需要本轮或之后的主线程序读取；普通旧资料仍导出旧v1。它不是完整材料包或账户备份，附件和整个实例仍使用各自导出/备份功能。详情见[数据契约](../rfcs/0014-paper-metadata.md)与[备份管理](BACKUP_README.md)。

## 引用一个明确版本

阅读作品并选择版本后，在“引用与发表快照”下载该版本的BibTeX。正文引用固定正文及其论文资料，不包含后来追加的附件。引用使用稳定ID与摘要；页面中的私有链接只适用于能访问同一实例的人，没有自动生成DOI或公开发表证明。

## 固定正文与所选附件

原发表账户可以展开“固定本版发表快照”，明确勾选需要包含的材料，再创建。没有附件也可固定正文和论文资料。未勾选及后添材料不进入快照；刷新或上传新文件不会自动选入之前排除的材料。

列表中的固定快照页展示当时正文原文、论文资料和材料清单，可下载快照BibTeX、单个原始附件或完整包。它的独立链接为 `/?snapshot=UUID`；恢复到另一地址后使用同一ID。正文内指向实时附件的图片不会在固定页自动加载，以免混入清单外的材料；“回到本版讨论与作者声明”仍可查看通常的排版阅读和评论。

完整包包含原始字节，离线核对使用：

```bash
python -m eksmu verify-publication 下载文件.json --expect-sha256 独立保存的快照摘要
```

核验只复算内容，不联网、不执行附件，也不证明作者、原创性或可信外部时间。原文和摘要同时被替换时，需要独立保管的预期摘要才能识别；当前没有链上证明。快照包也不能代替包含账户、个人清单、评论和声明历史的整库备份。

## 私有本地内容承诺

已下载完整快照包后，可以在本机生成带随机数的证据包，再在另一台离线机器复算：

```bash
python -m eksmu create-time-evidence 快照包.json 私有证据包.json
python -m eksmu verify-time-evidence 私有证据包.json --expect-commitment 单独保存的承诺SHA256
```

创建命令只写入一个新文件，不连接服务、数据库或公共链；输出中的`commitment_sha256`可另外保存用于日后比对。证据包含全部正文、附件和随机数，请按私有研究资料保管。核验成功表示包内材料与本地承诺一致，状态固定为`local_only`。本站时间和作者自述会分开显示，没有公开发表事件或可信外部时间证明。若随机数、附件或包缺失，无法完成相应核验。具体编码和固定测试向量见[RFC0016](../rfcs/0016-local-time-evidence.md)。

固定快照页现将作者自述、本站时钟、公开发表事件和外部时间证明分别显示。页面不会自动生成或保存上述私有证据包；没有证据包时也不能推断作者未在别处存证。外部锚定仍明确禁用，准备边界见[RFC0017](../rfcs/0017-external-anchor-preparation.md)。

## 作者说明与撤回

原发表账户可追加说明、撤回整项作品或恢复已撤回作品，必须填写原因。撤回覆盖所有版本，但正文、旧快照和他人讨论保留；提交新正文不自动取消撤回。版本页和固定快照页显示当前作者状态，并保留声明历史；旧下载包不会因后来撤回而改变，请回到实例核对最新状态。

若创建快照或提交声明时网络响应丢失，使用“重试待确认操作”发送原请求，不会重复登记。取消本机待确认不会删除服务器可能已经保存的记录。

格式、限额和备份兼容见[RFC0015](../rfcs/0015-publication-snapshots.md)。
