# 社区体验 Alpha 1

让好奇相遇，让探索继续。

这个版本把已有发表、评论、修订和验证工作台连成一个更完整的社区参与体验。基于主分支 `193b8267b2d03ea1576ea40598ef4eee4d50f858`，沿用现有主线实现，没有另建第三套验证协议。2026-09-20补齐同步后，Alpha1功能已作为完整Alpha2的一部分进入main，源码提交 `09c7731fd02ca81133cbc2f8ae81ca00249b90f1`。

## 现在可以做什么

从首页选择“提出一个问题”“分享一段发现”或“记录一次尝试”，以化名发表。打开自己的探索后，可以添加主题和协作介绍，让别人知道你希望一起讨论、复现或检查什么。

发现页支持关键词与主题筛选，以及全部探索、等待他人回应、寻找协作、我的关注、我的收藏和我的探索。排序可以选择最近发表或最近有进展，不按学历、资金或学术评分决定作品能否出现。

关注用于收到后续进展；收藏用于自己的阅读清单，两者分别处理。作者会收到他人的评论和分析；评论者被回复时也会收到提醒。关注者收到关注之后的新评论、分析和版本。作品作者、任务发起者和当时的参与者也会收到其他人的任务动态；退出后仍可看旧动态，之后的新事件不再提醒。自己的操作不通知自己。点击提醒打开当时的具体版本，标为已读不会吞掉之后的新回应。具体收件规则见[RFC0018](../rfcs/0018-collaboration-notifications.md)。

作品页可复制包含探索ID和版本ID的链接。当前地址属于本机实例；部署完成后才能作为可公开访问的入口。首页不会伪造用户数、成果或合作机构。

## 启动

```bash
python -m eksmu serve
```

在同一台电脑打开 `http://127.0.0.1:8765`。原有验证工作台仍可用：

```bash
python -m pip install -r requirements-receipts.txt
python -m eksmu serve --with-verification
```

不使用浏览器的两人参与演示：

```bash
python scripts/demo_community.py
```

演示创建临时数据，通过真实本机HTTP完成发表、搜索、关注、回应、修订提醒和个人清单恢复，随后清理临时文件。

## 数据与迁移

原作品、版本、评论和分析格式不变。新增主题、协作介绍、关注、收藏和已读状态保存在独立的 `<原数据库路径>.community.sqlite` 中。

主题和协作介绍由作者修改，带版本冲突检查和修改记录；其他人仍可以自由评论和独立验证。关注和收藏是个人记录，不公开成排行榜。

“带走我的资料”提供作品记录导出和个人清单导出。换实例时，先按既有命令导入作品、恢复原身份，再导入个人清单。个人备份可恢复自己的主题介绍、关注、收藏和已读记录，不包含身份秘密，也不能修改别人的介绍。协作动态的已读状态要求目标实例已有相应协作事件且当前身份有权查看。恢复后的关注从本实例恢复时开始通知，不重放迁移前的全部历史。

当前前端通知默认展示最近50条，点“刷新动态”更新；还不是推送服务。分页基于当前快照，持续新增内容时重新刷新会改变页位置。搜索范围为最新版标题、正文、主题和协作介绍，不是语义搜索。大规模负载、主题演化和完整管理工具安排在后续产品迭代。
