# RFC0024：创立期自愿 Lean 预检的私有任务契约

状态：2026-09-23，私有原型实现顺序。此活动不改变发表、讨论、论文引用、学术评价或任何资金状态；不是孙宇晨数学奖官方服务。

## 报名与版本绑定

只有已登录的正文版本作者可主动将该版本的一份 `.lean` 附件加入本站私有预检。报名固定正文版本 ID/摘要、附件 ID/原始字节摘要、目标 Lean 声明名、作者填写的问题来源、一次操作 ID 与授权范围。授权必须显式包含本站本机检查、私有结果、不向外提交；默认不参加。重复操作 ID 与完全相同输入返回原报名，冲突输入拒绝。新版本或新附件不得继承旧报名。撤回在任务启动前阻止运行；已产生的私有报告为审计而留存，不自动外发。没有 `.lean` 附件仍可发表和协作。

任务队列与报告保存在研究侧库，并进入整库备份；普通作品导出、个人清单和公开记录不包含私有任务或日志。只有报名作者可用网页读取自己的报名和报告。离线工作进程需先取得实例独占锁，读取一项仍有效且未运行的任务，将附件字节复制到隔离目录运行，然后回写绑定摘要的分层报告。任务运行时服务停服，避免跨库并发与未经授权的管理员网页权限。任务日志可能含作者私有材料，不能提交 Git、Issue 或外部模型。

## 检查层次

本站单文件预检使用固定的 Lean 4.34.0 二进制，附加目标 `#check` 与 `#print axioms`；原始附件摘要和附加指令后的输入摘要分别记录。用户命名空间、独立挂载/PID/网络命名空间、只读系统与工具链、无宿主家目录、清空传入环境、无网络、cgroup 内存/进程数和 CPU/时间/日志/暂存容量限制必须实际验收。无法建立隔离时任务留在队列，不在宿主直接执行。

Lean 退出零只表示这份单文件及所需导入在该工具链下处理完成；若目标依赖 `sorryAx`，报告标记证明缺口。其它公理依赖仍需逐项复核，不能靠字符串匹配自动认定证明完全可信。本站没有自动确定原题与形式命题的对应、完整覆盖、循环假设或独立内核重放。单文件检查不是完整 Git/Lake 项目构建；官方公开 `audit.py` 的 `preflight/prepare/run` 还须按其固定版本、原始仓库与隔离要求另接。本站结果与官方 PR、获奖、付款保持不同字段，初始均为空/未提交。

执行器在原文件后附加带随机任务标记的目标检查与公理查询，只有 Lean 零退出且首尾标记均出现在受限输出内，才记录 `lean_process_ok`。输出是可由材料影响的检查日志，标记及 `sorryAx` 字符串仅作为本次观察证据，不构成对抗性独立证明。作者可将绑定本站版本及附件摘要的准备草稿下载到本机；草稿不含私有检查日志，明确留出原始仓库、完整提交 SHA、语义映射、覆盖、许可和公开文件清单，绝不自动发送。

## 对外边界

报名只授权本实例的固定输入私有计算，不授权把正文、附件、日志或署名发给主办方、模型或其他参与者。提交草稿可在本机生成供作者审阅；作者本人决定并实施正式外发，平台不自动创建 PR、邮件或领奖申请。任何外部状态只读跟踪也应写明来源和采集时间，不能从本站 Lean 退出码推导官方认可。

## 验收

未报名及检查失败不妨碍发表。两身份权限、旧版/新附件摘要、重复请求、撤回前后、响应丢失、恢复后的队列与私有日志需核对。真实 Lean 小证明、含 `sorry` 目标、错误目标、宿主文件/网络隔离和超时必须用实际工具执行，模拟输出不计入这部分。工作进程无法取得锁或隔离工具缺失时不得运行附件。分层报告明确工具、版本、目标、实际范围与局限；不得出现“全文成立”“官方已验”“获奖”推断。
