# RFC0013：账户、设备会话与恢复（M2）

2026-09-22，M2实施契约。保留原作者UUID；当时界面以化名描述显示名称。具体凭证方案是本轮工程选择，不是实名或参与资格规则。历史RFC0002/0004是候选资料，本轮不直接合并其记录格式。

2026-09-23用户澄清：不要求机构资格，并不表示要隐藏真实姓名或单位。显示名称可以是真实姓名，也可以是笔名；作者自愿公开单位应有明确入口。当前恢复文件注册只是私有原型实现，不应被当作正式站点的身份政策。需要单独决定更常见的登录与找回方式，再迁移现有账户；迁移须保留作者UUID、作品和撤销状态。此补记不改变下文对**已安装M2实现**的准确描述。

1. 作者记录及历史摘要不改写。账户状态保存在主库的独立私有表，作品导出仍只包含作品记录。旧身份第一次通过登录接口迁移后，旧密钥仅作为恢复凭证，不能继续直接编辑；新账户从一开始使用分离的恢复凭证与会话。
2. 恢复凭证与会话均为32字节随机秘密。服务器只保存摘要；浏览器使用HttpOnly、SameSite=Strict、限定 `/api` 路径的会话Cookie。当前只有回环HTTP+SSH入口，Cookie没有Secure属性，不能直接用于公网部署。账户不要求邮箱、密码、钱包、学历或付费。
3. 注册与更换恢复凭证先在客户端生成候选并下载备份，确认保存后提交。待完成操作暂存当前标签页的sessionStorage；成功后移除秘密，恢复凭证不长期写入localStorage。登录也保留待完成请求，网络错误不当作失败提交。请求ID和完整请求摘要用于幂等重试，已撤销或过期的会话不能被重试复活。
4. 登录新建独立设备会话，绝对有效期7天；可以查看自己的有效会话、撤销某个会话、退出当前会话或退出其他会话。更换恢复凭证须出示当前恢复凭证，撤销所有旧会话并产生新会话；历史恢复凭证不得复用。恢复材料全部遗失时不承诺找回。
5. HTTP修改请求在跨进程写入锁内重新鉴权，直到相关写入完成才释放，保证撤销与修改的先后可判定。主库记录写入另在SQLite写事务内复核凭证。锁不赋予本机恶意进程隔离能力；直接持有数据库的管理员仍是受信运行者。
6. 全实例备份包含账户私有表，但恢复总是撤销全部会话并进入凭证核对状态，不直接启用备份内的恢复凭证。新增离线管理命令从同一实例、操作者明确选定的较新数据库核对作者及恢复凭证代数，保留较新撤销状态；核对完成后仍须重新登录。无法取得较新状态时保留阻断，不自动信任旧凭证。
7. 同一服务的账户状态不宣称具有跨实例或全球效力。普通作品包不是账户状态备份；旧版本实例不会自动获得本次撤销信息。M1旧备份需先使用匹配源码恢复，再按明确的账户升级/核对流程处理。

接口：`POST /api/auth/register`、`login`、`rotate`、`logout`、`revoke`、`revoke-others`；`GET /api/auth/status`、`sessions`。业务API接受新会话Bearer或浏览器Cookie；未迁移身份保留旧Bearer兼容路径。注册/登录/轮换请求包含预生成的会话秘密与操作ID，不从URL传递秘密。拒绝混用Bearer和当前服务Cookie，避免身份含混。

验收须包含两身份/独立客户端、旧身份迁移与作者归属、跨身份越权、单会话和全会话撤销、过期、轮换/写入并发、响应丢失重试、重启、Cookie属性、无秘密导出、旧备份恢复阻断及较新凭证核对。界面须展示失败和待确认状态；真实浏览器与用户电脑SSH隧道验收分别记录。

技术依据：[Python secrets](https://docs.python.org/3.11/library/secrets.html)、[OWASP会话管理](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html)、[MDN Set-Cookie](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Set-Cookie)。32字节随机数、会话过期和Cookie属性按本地私有原型范围采用；这不是完整公开认证服务的安全认证。
