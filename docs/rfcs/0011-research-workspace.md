# RFC 0011：研究表达、版本材料与开放协作

日期：2026-09-20。状态：本地实验性实现，对应 Issue #2。

## 架构

保持 `oic/store.py` 的记录契约和发表入口不变。`research.py` 使用独立 SQLite 保存原始材料、图片预览、协作任务、参加者及追加事件；`research_http.py` 连接现有身份校验；`research.js` 接到既有探索页面，不建立另一套社区。

阅读：固定参数 Pandoc 从标准输入读取 Markdown，输出 HTML5/MathML，再重建允许的标签、链接和属性。用户不能提供转换器命令或参数，原始 HTML 和原始 TeX 执行被禁用；转换时不获取外部图片，不使用浏览器 CDN。网络图片改为文字提示，本机生成的预览可显示。内部锚点加专属前缀，避免正文标识覆盖界面控件。

## 参与与协作

任何已有参与身份都可以在任何探索版本发起自己的具体任务；不要求学术身份、论文作者批准或验证成功。多人同时参加，没有唯一认领者。参加者可以记录自己的进展或退出；发起者可以结束或重开自己的任务；历史事件保留，完成任务不等于证明论文正确。

本版材料由作者追加，其他人的独立材料可通过自己的探索及讨论分享。这个边界保护原文的可追踪归属，不授予作者对批评或其他人研究的管理权。

## 版本与恢复

附件绑定版本，但可以在其发表后追加，因此独立保存材料清单摘要与上传时间；不把该摘要当成原文首次发表时的承诺。恢复材料需要同一个原文摘要与作者身份。原始文件以 SQLite BLOB 原子保存；批量恢复验证后在事务内执行，发生错误整体回滚。

任务版本使用乐观并发校验，事件追加保存。材料恢复已实现，协作快照可导出但不可自动导入为活动任务。完整实例备份与多人恢复在下一迭代完成。

## 本轮范围

图片、PDF、代码及小型数据附件，公式与代码排版，正文差异，具体任务/参加/进展/结束/重开。文件和协作配额不成为发表资格。保留原有验证工作台。本轮不新增通用代码执行、公开部署或链上资金机制。

技术参考：Pandoc 手册关于 Markdown、MathML、sandbox 和固定输入方式，https://pandoc.org/MANUAL.html ，查阅于2026-09-20。`--sandbox`是转换器限制，不代表已建成执行任意程序的系统级沙箱。
