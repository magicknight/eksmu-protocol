# 设计 RFC 与工程记录 · Design RFCs

本目录保存 Eksmu 从 2026 年 9 月起的设计文档（RFC 0001—0032），按编号记录每项功能当时的契约、取舍与验收方式。它们是历史工程记录，不是营销材料；旧文档中的状态行反映写作当时的进度，以代码和测试为准。

阅读约定：

- **“用户”** 在这些文档里指项目创办者（产品方向的决定人），不是平台上的普通使用者；“作者”“读者”才指平台使用者。
- **“维护者 AI”/“AI”** 指创办者委托编写代码与文档的 AI 编程助手。按 [CHARTER.md](../../CHARTER.md)，任何模型都不拥有学术裁决权；凡涉及隐私、资金、对外发布和权限的事项都需创办者单独授权。
- 文中提到的 `PROJECT_STATE`、`SOURCE_RECORD`、`ROADMAP`、ADR 0003 以及 `reports/` 是维护者的私有工作记录（含个人通信与运维细节），未随本仓库公开，相应链接已转为纯文本。
- `0032-archive-authorization-contract.md` 是 RFC 0032 的补充契约，共用编号。
- 2026-10-29 前项目工作名为 Open Inquiry Community，代码包名为 `oic`；旧文档中的 `oic.` 格式前缀与路径对应今天的 `eksmu.`。

These RFCs are written in Chinese. “用户” (the user) means the project founder; “维护者 AI” is the AI coding assistant the founder uses. Private working records referenced by name (PROJECT_STATE, SOURCE_RECORD, ADR 0003, reports/) are not part of this repository.
