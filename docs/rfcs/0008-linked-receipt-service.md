# RFC 0008：持久任务与签名回执的最小整合

日期：2026-09-20。状态：实验性实现；不是生产协议或已表决的社区制度。

## 决定

保留 v0.2 社区记录格式，不在作品记录中添加评审准入字段。使用 `verification_lab.protocol.revision_binding` 复用明确的版本绑定规则，使用 `oic_receipts` 执行受限真实计算和回执核验。fixture 工作流及其 HMAC 模拟票据不转换为真实结果。

新建 `oic_bridge` 单独数据库，任务包含请求者 ID、原版本快照、准备请求和取消时间；执行记录包含操作 ID、允许执行时间、执行请求与签名回执。身份认证仍由社区 HTTP 层完成，仅把参与者 ID 和读取的版本交给桥接层。

## 权利与权限

发表不读取验证状态。任何本地参与者都能独立检查别人的作品；只控制自己创建的任务，不能取消其他人的检查。验证失败、配额耗尽、密钥丢失或依赖不可用不禁用发表。普通评论和来源声明报告与工具回执分开展示。

## 生命周期

准备使用 record_only，不运行计算；每次新执行明确同意 local_builtin_opt_in。同一个 operation_id 幂等，另一个 ID 为重试且保留历史。SQLite 事务保障单次记录一致，当前有界计算同步完成；取消只阻止其后执行，不声称能中断正在运行的任务。

## 信任范围

执行回执通过 Ed25519 认证，并由接收方重算。接收方独立提供预期公钥。原版本摘要、检查输入和范围必须匹配；源文到形式输入的语义对应仍由人或其他工具讨论。

任务创建者、同意时间和取消状态属于本地服务记录，不因回执签名而成为跨节点身份认证。时间戳不是发现优先权。当前一个本机签名者，未完成生产密钥撤销、联邦信任或外部验证者登记。

## 迁移与失败

作品与任务分别导出。任务导出带源版本与执行回执，可独立验签和重算，不含私钥。任务导入及跨节点续跑尚未实现。验证密钥丢失时停止验证，不自动替换已有身份；作品服务继续可用。不同服务数据库禁止混用。

## 已运行的检查

新增50项服务／HTTP测试，含明确授权、他人任务控制、并发幂等、失败回滚、配额、取消后保留、版本变更、导出隐私和错误数据库拒绝。全套组合205项通过，另8项隔离界面测试通过。真实浏览器HTTP仍被环境策略阻挡。

## 后续 RFC

独立工作进程与领取凭证；签名者选择、登记与撤销；请求者授权签名；任务备份与恢复；真正隔离的 Lean 执行；多作者贡献与候选身份升级。公开网络、资金与外部模型调用仍另行授权。
